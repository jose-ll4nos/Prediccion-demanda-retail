# 📈 Análisis Predictivo de Demanda y Optimización de Inventarios

## 🎯 Problema de Negocio
Predecir la demanda a 12 meses vista para optimizar la planificación estratégica de inventarios, reduciendo el stock de seguridad y evitando quiebres de stock.

## 🛠️ Tecnologías Utilizadas
* **Lenguajes:** Python, SQL, DAX
* **Librerías:** Prophet, Pandas
* **Data Viz:** Power BI, Excel Avanzado

## ⚙️ Metodología
1. **Ingeniería de Datos:** Extracción y estructuración de más de 10,000 registros históricos (3 años) utilizando consultas avanzadas en SQL (JOINs y funciones de ventana).
2. **Modelado Predictivo:** Implementación de un modelo de pronóstico de series temporales con Prophet.
3. **Visualización y KPIs:** Diseño de un dashboard ejecutivo interactivo para filtrar categorías y evaluar tendencias.

## 📊 Resultados y Valor Agregado
* **Precisión del modelo:** Error absoluto medio porcentual (MAPE) inferior al 15% sobre datos de validación.
* **Impacto Financiero:** Cuantificación de un crecimiento proyectado de la demanda del 15.6%, facilitando las decisiones del área de operaciones y finanzas.

*(Nota: En los archivos de este repositorio puedes encontrar el código fuente en Python y las evidencias visuales del Dashboard).*
